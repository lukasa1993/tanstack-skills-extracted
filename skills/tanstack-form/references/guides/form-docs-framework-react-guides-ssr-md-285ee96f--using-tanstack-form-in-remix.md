### Remix Prerequisites

- Start a new `Remix` project, following the steps in the [Remix Documentation](https://remix.run/docs/en/main/start/quickstart).
- Install `@tanstack/react-form`
- Install any [form validator](./form-docs-framework-react-guides-validation-md-d751e17c.md#source-form-docs-framework-react-guides-validation-md) of your choice. [Optional]
