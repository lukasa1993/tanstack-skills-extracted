## Server-side rendering

Pass `platform` to `provideHotkeys` from the incoming request so the server renders the right labels, or render labels only in the browser on prerendered pages. See [SSR & Hydration](./hotkeys-docs-framework-angular-guides-ssr-md-05bcc1b5.md#source-hotkeys-docs-framework-angular-guides-ssr-md) for Angular SSR, Analog, and static page examples.
