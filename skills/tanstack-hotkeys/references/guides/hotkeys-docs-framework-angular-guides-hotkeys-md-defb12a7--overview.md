# Hotkeys — Overview

[Guide and prerequisites](./hotkeys-docs-framework-angular-guides-hotkeys-md-defb12a7.md) · Release-matched documentation · `@tanstack/hotkeys@0.17.0`.

`injectHotkey` registers a keyboard shortcut for as long as the component that injects it exists, and `injectHotkeys` registers several. Both functions take the same hotkeys and options. To register hotkeys outside Angular components, use the [hotkey manager](./hotkeys-docs-framework-angular-guides-hotkey-manager-md-190fe5ab.md#source-hotkeys-docs-framework-angular-guides-hotkey-manager-md).
