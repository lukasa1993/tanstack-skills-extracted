# Hotkeys — Overview

[Guide and prerequisites](./hotkeys-docs-framework-preact-guides-hotkeys-md-c4606a30.md) · Release-matched documentation · `@tanstack/hotkeys@0.17.0`.

`useHotkey` registers a keyboard shortcut while the component that calls it is mounted, and `useHotkeys` registers several. Both hooks take the same hotkeys and options. To register hotkeys outside Preact components, use the [hotkey manager](./hotkeys-docs-framework-preact-guides-hotkey-manager-md-60f997b1.md#source-hotkeys-docs-framework-preact-guides-hotkey-manager-md).
