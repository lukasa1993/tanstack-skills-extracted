# Hotkeys — Overview

[Guide and prerequisites](./hotkeys-docs-framework-solid-guides-hotkeys-md-56136a55.md) · Release-matched documentation · `@tanstack/hotkeys@0.20.0`.

`createHotkey` registers a keyboard shortcut while the component that calls it is mounted, and `createHotkeys` registers several. Both primitives take the same hotkeys and options. To register hotkeys outside Solid components, use the [hotkey manager](./hotkeys-docs-framework-solid-guides-hotkey-manager-md-d1ae34aa.md#source-hotkeys-docs-framework-solid-guides-hotkey-manager-md).
