# Vue Hotkeys — API

[Guide and prerequisites](./tanstack-vue-hotkeys-ef953b39.md) · Published skill · `@tanstack/vue-hotkeys@0.27.0`.

## API

| API                                       | What it's for                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useHotkey(hotkey, callback, options?)`   | Register one chord, sequence, or app hotkey while the component is mounted; the hotkey and options can be refs or getters.                                                                                                                                                                                                                                                                           |
| `useHotkeys(definitions, commonOptions?)` | Register several hotkeys, or a ref or getter of a list built from data, in one call.                                                                                                                                                                                                                                                                                                                 |
| `<HotkeysProvider>`                       | Set default options, a scope (`exclusive` for dialogs), `enabled`, `suspendCharacterKeys` (set from a user setting that turns off single-key shortcuts; it applies app-wide while the provider is mounted), and app hotkeys for its children, and emit `custom-hotkeys-change`.                                                                                                                      |
| `provideHotkeysContext(options)`          | Provide the same options from a component's setup instead of rendering `HotkeysProvider`; they apply to its children.                                                                                                                                                                                                                                                                                |
| `useHotkeysContext()`                     | Read the nearest provider's merged defaults and enabled state, or `null` outside a provider.                                                                                                                                                                                                                                                                                                         |
| `useDefaultHotkeysOptions()`              | Read the default options merged from every provider above.                                                                                                                                                                                                                                                                                                                                           |
| `useFormatForDisplay()`                   | Get the function that formats a hotkey as a label, with the provider's `platform` and the user's keyboard layout filled in. Only Chromium browsers report a layout, so physical keys keep their US labels in Firefox and Safari. Use it for every label in a component: `const formatForDisplay = useFormatForDisplay()` in `setup`, then `formatForDisplay(hotkey)`.                                |
| `useFormatForAria()`                      | Get the function that formats a hotkey for `aria-keyshortcuts`, with the provider's `platform` and the user's keyboard layout filled in. Returns `undefined` for a multi-step sequence, no hotkey, or a hotkey that can't fire right now, such as a disabled or suspended one, so the attribute is omitted. Set `aria-keyshortcuts` on every control that has a shortcut, next to the visible label. |
| `useAppHotkeys()`                         | Get a computed ref of the declared app hotkeys with the user's custom hotkeys applied.                                                                                                                                                                                                                                                                                                               |
| `useAppHotkeyList()`                      | Get a computed ref listing every app hotkey with its status, for a cheat sheet or settings screen.                                                                                                                                                                                                                                                                                                   |
| `useCustomHotkeys()`                      | Read, change, and reset the user's custom hotkeys, and check a new one for conflicts.                                                                                                                                                                                                                                                                                                                |
| `useHotkeyRecorder(options)`              | Record a chord or sequence the user presses; destructure the refs it returns.                                                                                                                                                                                                                                                                                                                        |
| `useHotkeyRegistrations()`                | Get a ref listing every registered hotkey with its options, `meta`, and `status` (whether it's enabled and in an active scope).                                                                                                                                                                                                                                                                      |
| `useHotkeyScopesState()`                  | Get a ref of the active scopes and the exclusive scope that owns the keyboard.                                                                                                                                                                                                                                                                                                                       |
| `useHotkeyHint(hotkey, options?)`         | Get a computed ref of whether held modifiers should reveal a shortcut's hint. False unless a registration of the hotkey can fire: enabled, in an active scope, and with focus inside its element target.                                                                                                                                                                                             |
| `useKeyHold(key)`                         | Get a ref of whether one key is held. Letters match in any case; other names, such as `Shift`, are case-sensitive.                                                                                                                                                                                                                                                                                   |
| `useKeyLockState(key)`                    | Get a read-only ref of whether `'CapsLock'`, `'NumLock'`, or `'ScrollLock'` is on: `true`, `false`, or `null` until a key press, click, or mouse move reports it. Accepts a ref or getter. Resets to `null` when the window loses focus. Num Lock and Scroll Lock are always `null` on macOS and iOS. Use it for lock state, not `useKeyHold`, which is true only while the key is down.             |
| `useHeldKeys()`                           | Get a ref of every key that's held right now.                                                                                                                                                                                                                                                                                                                                                        |
| `useHeldKeyCodes()`                       | Get a ref mapping each held key to its physical `event.code`.                                                                                                                                                                                                                                                                                                                                        |

The package also re-exports `@tanstack/hotkeys`, such as `matchesKeyboardEvent` and `defineAppHotkeys`. Its plain `formatForDisplay` export is deprecated: use `useFormatForDisplay()` in components. Outside a component, call the plain function and pass `platform`. The plain `formatForAria` export is deprecated the same way, in favor of `useFormatForAria()`.

No provider is required. Call the composables synchronously in setup.
