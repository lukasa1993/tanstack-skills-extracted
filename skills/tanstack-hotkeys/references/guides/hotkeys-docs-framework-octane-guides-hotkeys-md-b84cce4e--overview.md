# Hotkeys — Overview

[Guide and prerequisites](./hotkeys-docs-framework-octane-guides-hotkeys-md-b84cce4e.md) · Release-matched documentation · `@tanstack/hotkeys@0.16.0`.

`useHotkey` registers a keyboard shortcut while the component that calls it is mounted, and `useHotkeys` registers several. Both hooks take the same hotkeys and options. To register hotkeys outside Octane components, use the [hotkey manager](./hotkeys-docs-framework-octane-guides-hotkey-manager-md-1ee89e7f.md#source-hotkeys-docs-framework-octane-guides-hotkey-manager-md).
