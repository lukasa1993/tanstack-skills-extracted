# Hotkeys — Overview

[Guide and prerequisites](./hotkeys-docs-framework-octane-guides-hotkeys-md-b84cce4e.md) · Release-matched documentation · `@tanstack/hotkeys@0.36.0`.

`useHotkey` registers a keyboard shortcut while its component is mounted, and `useHotkeys` registers a list of them. Both hooks accept the same bindings and options. To register hotkeys outside Octane components, use the [hotkey manager](./hotkeys-docs-framework-octane-guides-hotkey-manager-md-1ee89e7f.md#source-hotkeys-docs-framework-octane-guides-hotkey-manager-md).
