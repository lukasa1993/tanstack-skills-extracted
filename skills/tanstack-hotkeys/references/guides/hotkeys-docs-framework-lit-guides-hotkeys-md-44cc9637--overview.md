# Hotkeys — Overview

[Guide and prerequisites](./hotkeys-docs-framework-lit-guides-hotkeys-md-44cc9637.md) · Release-matched documentation · `@tanstack/hotkeys@0.20.0`.

The `@hotkey` decorator registers a keyboard shortcut for a method while its element is connected. `HotkeyController` does the same for any callback, and accepts a hotkey and options that change. Both take the same hotkeys and options. To register hotkeys outside Lit elements, use the [hotkey manager](./hotkeys-docs-framework-lit-guides-hotkey-manager-md-506c8dcc.md#source-hotkeys-docs-framework-lit-guides-hotkey-manager-md).
