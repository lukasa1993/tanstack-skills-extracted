# Installation

<a id="source-query-docs-framework-svelte-installation-md"></a>

Release-matched documentation · `@tanstack/svelte-query@6.2.3`.

[Topic index](../framework-svelte.md) · [Source provenance](../SOURCES.md)

You can install Svelte Query via [NPM](https://npmjs.com).

### NPM

```bash
npm i @tanstack/svelte-query
```

or

```bash
pnpm add @tanstack/svelte-query
```

or

```bash
yarn add @tanstack/svelte-query
```

or

```bash
bun add @tanstack/svelte-query
```

> Wanna give it a spin before you download? Try out the [basic](https://github.com/TanStack/query/blob/413ba6e30b72a89ad71710c91633c3099638fd56/examples/svelte/basic/README.md) example!
