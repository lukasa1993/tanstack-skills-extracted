# Virtualizer — Optional Options: `scrollEndThreshold`

[Guide and prerequisites](./virtual-docs-api-virtualizer-md-c3b477a3.md) · Release-matched documentation · `@tanstack/virtual-core@3.17.9`.

## Optional Options: `scrollEndThreshold`


```tsx
scrollEndThreshold?: number
```

**Default:** `1`

The pixel threshold used by `isAtEnd()` and `followOnAppend` to decide whether the viewport is close enough to the end to count as pinned.
